# HANDO_TRACK

## Production Tracking & Interdepartmental Handover System

HANDO_TRACK is a Flutter-based mobile application designed to digitize and organize production tracking and the handover of work between departments.

The system helps users manage projects, versions, job items, quantities, and delivery requests through a centralized workflow.

## Key Features

* User authentication
* Project and version management
* Job item tracking
* Quantity selection and delivery management
* Interdepartmental handover workflow
* Notifications for delivery requests
* Search and organized project navigation
* Arabic and English language support
* Centralized data management

## Technologies

* Flutter
* Dart
* Firebase
* REST APIs
* Git & GitHub

## Project Structure

The project is organized as a Flutter application with dedicated modules for the application interface, business logic, assets, and platform-specific configurations.

## Purpose

The goal of HANDO_TRACK is to replace manual production handover processes with a digital workflow that improves visibility, organization, and communication between departments.

### Prerequisites

* Flutter SDK
* Dart SDK
* Android Studio or Visual Studio Code
* A configured Android/iOS development environment

### Installation

```bash
git clone https://github.com/an464057-boop/HANDO_TRACK.git
cd HANDO_TRACK
flutter pub get
flutter run
```
